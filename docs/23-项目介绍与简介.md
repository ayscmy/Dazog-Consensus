# MSERM CRM · 项目介绍与简介

> 一份面向开发者、贡献者与使用者的项目总览。更完整的设计、数据模型与接口细节见仓库 `docs/` 下各专题文档。

## 一句话定位

**MSERM CRM** 是一款开源的**集团级销售与回款管理系统**，覆盖从**线索 → 商机 → 报价 → 合同 → 开票 → 回款**的全流程，基于 Node.js 原生服务 + SQLite，零第三方运行时依赖，开箱即用；亦可平滑切换到 PostgreSQL 支撑更大规模。

## 我们解决什么问题

- **流程割裂**：线索散落在表格、聊天与邮件里，商机、报价、合同各管各的，没人看得全。
- **回款不透明**：合同签了，但开票、回款进度说不清，财务与销售对不上。
- **集团管控弱**：多团队、多角色的权限与审批缺乏统一抓手。
- **对外对接难**：想把官网线索、投放数据与第三方客户池自动汇入 CRM，却要手写一堆接口。

MSERM CRM 用一套统一的数据模型把"线索到回款"串成闭环，并提供对外线索 API，让外部系统（官网、投放平台、客户名录）自动入池。

## 核心能力

1. **线索全流程**：线索公海（领取 / 分配 / 放回 / 自动回收）、商机、报价单、合同、开票、回款，状态可追踪。
2. **多用户与权限**：角色 / 部门 / 数据权限矩阵，配套审批流转。
3. **对外线索 API**：基于密钥 + IP/域名 + 限额授权，第三方可安全地向 CRM 投递线索（`docs/15-线索API接口(v1).md`）。
4. **客户名录对接**：独立部署版与官网 SaaS 通过"会员 + 额度"机制对接共享客户库（`docs/13-客户名录收费标准.md`）。
5. **轻量可部署**：Node 22 + SQLite 单文件起步，数据可导出，迁移方便。

## 技术架构亮点

- **零运行时依赖**：核心服务仅用 Node 内置模块，部署简单、攻击面小、易审计。
- **双存储支持**：默认 SQLite；可选 PostgreSQL（通过 `pg` 适配），随业务规模伸缩。
- **原生 HTTP 服务**：不绑定 Web 框架，代码可读、易二次开发。
- **开放接口**：清晰的 REST 契约与错误码，便于集成与自动化。

## 快速开始

```bash
git clone https://gitee.com/Emcloud_admin/mserm-crm.git
cd mserm-crm
npm install          # 仅 pg 为可选依赖
npm start            # 启动后访问 http://127.0.0.1:8081
```

> 首次启动会进入初始化引导；端口可在 `.env` 的 `PORT` 中修改（默认 8081）。

## 典型场景

- **集团销售管理**：多团队共用一套线索到回款流程，权限与审批可控。
- **独立部署**：私有化部署在公司内网，数据自持。
- **SaaS 对接客户名录**：通过会员机制对接官网共享客户库，按需扩充线索来源。
