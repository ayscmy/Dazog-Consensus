常见问题

动手之前，先把这几件事说清楚

开源仓库里为什么没有数据库？

数据库是运行态产物，随业务演进而变。放进 Git 会不断膨胀，也容易泄露真实客户资料与密码哈希。仓库只提供表结构与自动迁移，空库启动后由安装向导创建第一个管理员；需要演示数据就到官网会员中心下载。

下载的数据库怎么用？

把解压得到的 crm.db 放到项目 data/ 目录（覆盖同名文件前请先备份自己的库），然后 npm start。演示账号见压缩包内的《安装说明》，初始密码统一为 crm123456，登录后请立即修改。

需要什么运行环境？

Node.js ≥ 22.5（使用内置 node:sqlite）。不需要 Docker、不需要 MySQL、不需要 npm install，因为项目零第三方依赖。

可以商用吗？

可以。代码以 AGPL-3.0 发布：内部使用不受限制；若修改后以 SaaS 形式对外提供服务，需要开放修改后的源码。需要闭源分发或去除开源义务，可联系作者获取商业授权。

会员收费吗？会收集什么信息？

免费。注册只要求邮箱、称呼与公司名称，用于版本更新通知与下载统计；不会向第三方出售或共享。可随时在会员中心修改资料或联系管理员注销。
