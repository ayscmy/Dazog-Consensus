一、三个工具能力梳理

daily_stock_analysis

LLM 驱动的 A股/港股/美股 智能分析系统 · MIT · ~63k★
  • 核心LLM 生成「决策仪表盘」：核心结论、评分、买卖点、风险、利好催化、操作清单
  • 多市场：A股/港股/美股/日股/韩股/台股 + ETF
  • 15 种策略（均线/缠论/波浪/趋势/热点/事件/成长/预期…）
  • 多源行情：Tushare / AkShare / YFinance / 券商接口
  • 强项GitHub Actions 定时运行（零服务器）；飞书/企微/Telegram/Discord/邮件推送
  • Web/桌面工作台、历史报告、回测、持仓管理、CSV/Excel/剪贴板导入

a-stock-data

A股全栈数据工具包（Python）· 11层/54端点/19数据源 · 零鉴权为主
  • 行情层：mootdx/腾讯/百度K线/新浪 — K线含 MA5/10/20、五档盘口、PE/PB/市值
  • 研报层：研报列表/PDF、一致预期 EPS、NL 检索
  • 信号层：北向资金、龙虎榜、解禁日历、板块资金流、行业排名
  • 强项资金筹码层：融资融券、大宗交易、股东户数、**CYQ 筹码分布**、分红
  • 基础层：季报37字段、F10、财报三表、申万行业
  • 打板层：涨停池/炸板/涨停原因题材/连板梯队/重点监控
  • 期权层（ETF期权T型/IV）、舆情互动、宏观层（PMI/社融）
  • 工程限流防封 + 数据源优先级 + 本地缓存 + 降级策略

OpenBB

开源金融数据平台（ODP）· AGPLv3 · ~72k★
  • Python SDK + REST API + MCP Server + CLI + 桌面 app + Workspace（企业付费）
  • 30+ providers（FMP/FRED/Yahoo/Polygon/SEC…），OBBject 统一抽象
  • 资产：股票/期权/crypto/固收/宏观/另类
  • 强项宏观最强（FRED/PMI/央行/IMF/OECD）、美股/全球覆盖、AI Agent MCP
  • 架构：Fetcher 抽象 + provider registry，可扩展

三、融合架构：各取所长，不重复造轮子

现有 pc-dingpan（Node 代理 + analysis.js 引擎） → ① 数据补全层（Python，仿 a-stock-data） → ② LLM 叙事层（Hy3 + 引擎输出） → ③ 微信推送（二维码扫码绑定）
  • 数据层：保留 Node 代理（与现有 gen_*.py 一致），新增 gen_fund.py 借鉴 a-stock-data 直连 HTTP 逻辑，落 JSON 供 /api/fundamental 扩充「财报三表 + 股东户数 + 融资融券 + CYQ 筹码」。复用其限流/降级。**不打包 OpenBB 进 MIT 仓库**（AGPL 传染风险），仅借鉴 provider 抽象。
  • 分析层：保留 analysis.js 多周期决策引擎（我们的核心壁垒），叠加 daily_stock_analysis 的「决策仪表盘」思路——把引擎结构化结果喂给 Hy3 生成叙事化每日简报，而非纯数字。
  • 推送层：改用微信推送（替换原飞书 bot）。通过微信推送服务（WxPusher / Server酱 / PushPlus）生成订阅二维码，用户在微信扫一扫关注后即可自动接收；每日 15:30 收盘 / 20:50 夜盘前，把引擎输出 + LLM 摘要经微信通道推到用户微信，复用 daily_stock_analysis 的「零成本定时推送」机制。无需公众号认证（你的微信公众号未认证无 API，微信推送服务自带下发能力）。
  • 宏观层：用 a-stock-data 宏观层（PMI/社融/人民银行）+ OpenBB 思路补真实宏观，替代当前「沪金/原油代理价格」的粗略宏观。

微信推送落地机制（扫码绑定 → 自动推送）

你在微信推送服务注册应用（拿 appToken） → 生成订阅二维码（展示在 pc-dingpan 页面 / 自动发给你） → 用户微信扫码绑定 → 回传 UID → 定时（15:30 收盘 / 20:50 夜盘前）自动推持仓/复盘简报
  • 推荐方案 WxPusher：免费、稳定、自带服务号下发，无需自己公众号认证。流程：创建应用→appToken→用 createQrcode 接口生成用户绑定二维码→用户扫描后回调拿到 uid→调用 /api/send/message 发 markdown/文本卡片。
  • 备选 Server酱 / PushPlus：扫码登录拿 sendkey/token，接口更简单但偏「单用户」；多人订阅优先 WxPusher。
  • 代码落点：新增 push_wechat.py（Flask/HTTP 调用微信推送 API），或 Node 侧加 /api/wechat/bind + /api/wechat/push；二维码由后端生成并嵌到 dashboard。定时由现有 Node 任务调度（复用自动化 pipeline）。
  • 内容：复用分析引擎结构化输出 + Hy3 生成的叙事化简报，自动推送「当日持仓建议 / 复盘点评 / 次日关注」，不再依赖人工转发。

五、明确结论

  • 不必替换：我们的多周期价格行为引擎 + 期货决策链是核心壁垒，三个工具都不如我们在这块的实战化（5 层决策链 + 铁律）。
  • 最该补的：① 基本面/筹码深度（a-stock-data）→ 让选股从「价格行为」升级为「价格行为+基本面+筹码」；② 微信复盘推送（微信订阅推送）→ 把盯盘变成「收盘自动出报告」；③ 宏观真实数据。
  • 融合方式：保持 Node 主导、Python 辅助（与现有 gen_*.py 一致）；不用 AGPL 代码侵入主仓。
  • 已完成：P0 全部三项 + P1 宏观、数据源健壮性均已落地（2026-08-25）。基本面/筹码、打板题材、微信推送、北向宏观、K 线降级五项已验证通过。
  • 剩余待做：P1 回测模块（大）、P2 美股/港股视野（大，谨慎）、P2 ETF 期权链（中）——需另行排期，收益与投入需再评估。
